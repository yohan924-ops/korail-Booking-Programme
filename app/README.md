# `app/` — 코레일 예매 GUI

`src/korail_mobile_api` 가 라이브러리이고, 여기는 그것을 쓰는 **프로그램**입니다.
배포되지 않습니다(`pip install` 에 들어가지 않음). 저장소에서 바로 실행합니다.

```bash
python3 app/main.py
```

의존성은 라이브러리와 같습니다 — `httpx`, `cryptography`, 그리고 파이썬에 딸린
Tkinter. 리눅스에서 `ModuleNotFoundError: No module named 'tkinter'` 가 나면
`sudo apt install python3-tk` 하세요. macOS·Windows 의 공식 파이썬에는 들어 있습니다.

## 화면

1. **로그인** — 아이디·휴대폰번호·회원번호 중 아무거나. 무엇인지는 라이브러리가
   값의 모양을 보고 고릅니다(`infer_login_input_flag`). 비밀번호는 저장하지
   않습니다.
2. **열차 조회** — 구간·날짜·시간창·열차 종류·좌석 등급(일반/특실/무관),
   직통과 환승, 환승역과 환승시간(몇 분 이상, 몇 분 이하), 승객 5종.
3. **열차 목록** — 직통은 한 줄, 환승은 부모 줄(총 소요·환승역·환승시간) 아래에
   구간별 줄(구간 소요)이 붙습니다. 좌석 상태는 앱이 화면에 찍는 문구
   그대로입니다(`매진`, `여유`, `좌석부족`).
4. **자동예매** — 고른 열차(여러 개 가능)를 주기적으로 다시 조회하다가, 먼저
   열리는 것 하나에 결제 전 홀드를 만들고 멈춥니다. 잡으면 텔레그램으로
   알립니다.

## 안전

| 무엇 | 어떻게 |
| --- | --- |
| 결제 | **하지 않습니다.** 결제·환불·취소 범주의 consent 를 만드는 코드가 이 폴더에 없습니다(시험이 원문으로 확인). |
| 실제 예약 | "실제 예약(홀드) 만들기" 체크가 꺼져 있으면 `dry_run=True` 라 예약 요청이 나가지 않습니다. 켜고 시작하면 확인 창이 한 번 더 뜹니다. |
| 중복 예약 | 하나 잡으면 그 자리에서 끝납니다. 재시도한 예약은 중복 예약입니다. |
| 요청 간격 | 두 겹입니다 — HTTP 훅 1.5초(화면에서 못 내림) + 조회 주기(기본 30초, 하한 10초, ±15% 흔들림). |
| 비밀번호 | 저장하지 않습니다. 설정 파일에 담을 필드가 아예 없습니다. |
| 텔레그램 토큰 | 사용자 홈의 설정 파일에 `0600` 으로 저장하고, 로그·화면 어디에도 찍지 않습니다. |

설정 파일 위치는 Windows `%APPDATA%\korail-booker\settings.json`, 그 밖에는
`~/.config/korail-booker/settings.json` 입니다. 저장소 안에는 아무것도 쓰지 않습니다.

## 할 수 없는 것

- **비회원 예매.** 라이브러리의 예약 경로가 로그인 세션을 요구하고, 폼 자체가
  회원 전용입니다(`ReservationRequest.java:105-119`). 이 프로그램이 우회할 수
  있는 것이 아닙니다.
- **입석+좌석 병합 예약(`1202`).** 두 번째 호출인 `reserve_merge` 가 실서버에
  나간 적이 없어, 반쯤 검증된 경로로 진짜 예약을 만들지 않습니다.
- **환승 예약대기.** 예약대기는 직통·일반실에만 있습니다. 라이브러리도 환승
  여정의 예약대기를 거절합니다.
- **가상대기실(NetFunnel) 대기 처리.** 명절 같은 대기열 상황은 다루지 않습니다.

## 환승 두 가지의 근거가 다릅니다

- **서버 추천 환승** — `search_transfer_trains` 가 짝지어 준 여정. 앱이 하는
  그대로이고, `reserve_transfer` 로 한 PNR 에 잡히는 것이 실서버에서
  확인됐습니다(2026-07-31 서울→오송→여수EXPO).
- **환승역 직접 지정** — 서버에 "이 역에서 갈아타는 여정을 달라"고 물을 방법이
  없어서(환승 검색 폼에 환승역 필드가 없습니다), 이 프로그램이 두 구간을 각각
  직통으로 조회해 붙입니다. 예약 폼은 만들어지지만 **서버가 이런 조합을
  받아들이는지는 확인된 바 없습니다.** 목록에서 주황색으로 표시하고, 자동예매를
  시작할 때 한 번 더 묻습니다.

## 텔레그램 알림 붙이기

1. 텔레그램에서 `@BotFather` 에게 `/newbot` — 봇 토큰을 받습니다.
2. 만든 봇과의 대화를 열고 아무 메시지나 한 번 보냅니다.
3. 프로그램의 **텔레그램 설정** → 토큰 붙여넣고 **내 대화 ID 찾기** → **테스트
   전송** → **저장**.

## 구조

| 파일 | 하는 일 | 네트워크 |
| --- | --- | --- |
| `korail_booker/journeys.py` | 소요·환승 시간, 좌석 상태 계산 | 없음 |
| `korail_booker/search.py` | 조회 → 여정 목록 | 클라이언트를 인자로 받음 |
| `korail_booker/autobook.py` | 자동예매 루프 | 클라이언트를 인자로 받음 |
| `korail_booker/notify.py` | 텔레그램 | `api.telegram.org` |
| `korail_booker/settings.py` | 설정 저장 | 없음 |
| `korail_booker/session.py` | 클라이언트 생성·로그인·페이싱 | KORAIL |
| `korail_booker/ui.py` | Tkinter 화면 | 없음(작업 스레드에 맡김) |

Tkinter 를 import 하는 파일은 `ui.py` 하나입니다. 그래서 화면 없는 CI 에서도
`tests/test_korail_booker.py` 가 나머지 전부를 시험합니다.
